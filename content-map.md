## Article Coverage

The reference sitemap contains a large collection of `/blog/*` guide pages. SmartStaker will provide a catch-all blog article route—`/blog/:slug`—so every public reference article URL pattern resolves. The article template will use a curated SmartStaker guide registry for title, category, summary, reading duration, and responsibly framed long-form content. Any slug not included in the initial curated registry will still render a clear generic guide page instead of producing a dead end.

## Shared Components

Every public page will share the same persistent header, mobile navigation, operating-strip announcement, product-preview action behavior, legal footer, and 18+ responsible-use disclosure. Product pages use the same large editorial hero, metric strip, feature cards, workflow sequence, FAQ accordion, and related-product rail. Game pages additionally include an interface-style configuration preview; it is visually faithful to the reference but expressly non-functional.

## Integrity Boundaries

SmartStaker copy preserves the reference information architecture but is re-authored under independent branding. The static site does not provide automation, downloading, account connections, affiliate tracking, code claiming, financial advice, or gambling functionality. All unavailable actions show a local preview notice.
